# Proyecto: Git & GitHub para Estadística y Python

Repositorio de ejemplo para la asignatura de Estadística y Python (UAP).
Incluye ejemplos de Streamlit, visualización y guía para uso de Git/GitHub.

Instrucciones rápidas:

- Crear y activar entorno virtual:

  python -m venv .venv
  .\.venv\Scripts\activate

- Instalar dependencias:

  pip install -r requirements.txt

- Ejecutar una app Streamlit (ejemplo):

  .venv\Scripts\python -m streamlit run practicaPuroStreamlit.py

- Ejecutar la app principal creada para despliegue:

  .venv\Scripts\python -m streamlit run practicaPuroStreamlit.py

- Desplegar en Streamlit Cloud:

  1. Sube tu proyecto a GitHub.
  2. En https://share.streamlit.io/ crea una nueva app.
  3. Selecciona tu repositorio y `app.py` como archivo de inicio.
  4. Haz deploy y comparte la URL resultante.
